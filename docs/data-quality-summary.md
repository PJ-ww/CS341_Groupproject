# สรุปผลการตรวจสอบคุณภาพข้อมูล (Data Quality Summary)

## 1. วัตถุประสงค์

เอกสารนี้จัดทำขึ้นเพื่อบันทึกผลการตรวจสอบคุณภาพข้อมูลที่ใช้ในโครงการ CS341 Flood Impact & Recovery ก่อนนำข้อมูลไปวิเคราะห์ด้วย Amazon Athena

การตรวจสอบครอบคลุมประเด็นสำคัญ ได้แก่
- จำนวนข้อมูลในแต่ละตาราง (Record Count)
- ข้อมูลซ้ำ (Duplicate Records)
- ข้อมูลที่ขาดหาย (NULL Values)
- ค่าตัวเลขที่ผิดปกติ เช่น ค่าติดลบและค่าศูนย์
- ความสอดคล้องของข้อมูลและข้อจำกัดในการนำไปใช้งาน

## 4. สรุปประเด็นด้านคุณภาพข้อมูล

จากการตรวจสอบทั้ง 7 ตาราง พบว่าไม่พบข้อมูลซ้ำทั้งแถว และสามารถระบุข้อจำกัดของข้อมูลแต่ละชุดได้

ประเด็นที่ต้องระมัดระวังเป็นพิเศษ ได้แก่

1. ค่า NULL ในบางตารางมีจำนวนมาก จึงไม่ควรแทนด้วยศูนย์โดยไม่มีเหตุผลรองรับ
2. ข้อมูลรายได้มีค่าติดลบ ซึ่งต้องตรวจสอบความหมายจากแหล่งข้อมูลต้นฉบับเพิ่มเติม
3. ข้อมูลสถิติหมู่บ้านมีจำนวน records ที่มีข้อมูลในแต่ละปีไม่เท่ากัน
4. ข้อมูลภัยพิบัติบางชุดมีหลายรอบรายงาน จึงต้องแยกตามรอบก่อนนำไปวิเคราะห์
5. ข้อมูลที่เชื่อมกันในระดับจังหวัดและปี ไม่สามารถนำไปสรุปความสัมพันธ์ในระดับครัวเรือนหรืออาชีพได้โดยตรง

## 6. สรุป

ผลการตรวจสอบแสดงให้เห็นว่าข้อมูลทั้ง 7 ตารางไม่พบข้อมูลซ้ำทั้งแถว แต่ยังมีข้อจำกัดด้านข้อมูลที่ขาดหาย ความแตกต่างของช่วงเวลา และระดับรายละเอียดของข้อมูล

การตรวจสอบเหล่านี้ช่วยให้สามารถเลือกใช้ข้อมูลได้เหมาะสม ลดความเสี่ยงจากการตีความผิด และทำให้ผลการวิเคราะห์ในโครงการมีความน่าเชื่อถือมากขึ้น
