# สรุปผลการวิเคราะห์ข้อมูล (Data Analysis Summary)

## 1. ภาพรวม

เอกสารนี้จัดทำขึ้นเพื่อสรุปผลการวิเคราะห์ข้อมูลจากโครงการ CS341 Flood Impact & Recovery โดยใช้ข้อมูลจากหลายแหล่งที่จัดเก็บไว้ใน Amazon S3 และจัดการ Metadata ผ่าน AWS Glue Data Catalog จากนั้นใช้ Amazon Athena ในการ Query และวิเคราะห์ข้อมูล

วัตถุประสงค์ของการวิเคราะห์ คือ เพื่อศึกษาระดับความเสี่ยงจากน้ำท่วม จำนวนครัวเรือนที่ได้รับผลกระทบ ข้อมูลด้านเศรษฐกิจและรายได้ รวมถึงงบประมาณที่เกี่ยวข้องกับภัยพิบัติ เพื่อใช้เป็นข้อมูลประกอบการตัดสินใจและวางแผนให้ความช่วยเหลือ

## 2. ผลการวิเคราะห์ข้อมูล

### 2.1 การวิเคราะห์ระดับความเสี่ยงทางภูมิศาสตร์

**ตารางที่ใช้:** `geographic`

จำนวนข้อมูลทั้งหมด 1,772 records

| ระดับความเสี่ยง | จำนวนข้อมูล | ร้อยละ |
|---|---:|---:|
| เสี่ยงต่ำมาก | 816 | 46.05% |
| เสี่ยงต่ำ | 466 | 26.30% |
| เสี่ยงปานกลาง | 162 | 9.14% |
| เสี่ยงสูง | 228 | 12.87% |
| เสี่ยงสูงมาก | 100 | 5.64% |
| **รวม** | **1,772** | **100%** |

**ข้อค้นพบ**
- พื้นที่ที่มีความเสี่ยงต่ำมากและความเสี่ยงต่ำรวมกันคิดเป็น 72.35% ของข้อมูลทั้งหมด
- พื้นที่ที่มีความเสี่ยงสูงและสูงมากรวมกันคิดเป็น 18.51%
- อำเภอมหาชนะชัยมีจำนวนพื้นที่ความเสี่ยงสูงและสูงมากรวมกันมากที่สุด จำนวน 108 records
- อำเภอเมืองยโสธรมีจำนวนพื้นที่ความเสี่ยงสูงมากมากที่สุด จำนวน 42 records

### 2.2 การวิเคราะห์ข้อมูลรายได้และกลุ่มเศรษฐกิจ

**ตารางที่ใช้:** `nso_income`

วิเคราะห์ข้อมูลรายได้ตามกลุ่มเศรษฐกิจและจังหวัด โดยเปรียบเทียบข้อมูลปี 2566 และ 2568

**ข้อค้นพบ**
- กลุ่มผู้ประกอบธุรกิจของตนเองที่ไม่ใช่การเกษตรมีค่าเฉลี่ยสูงที่สุด เมื่อเปรียบเทียบระหว่างกลุ่มเศรษฐกิจที่วิเคราะห์ในทั้งสองปี
- ในปี 2568 จังหวัดนครปฐมมีค่าเฉลี่ยสูงที่สุดที่ 18,592.46
- จังหวัดยโสธรมีค่าเฉลี่ย 8,199.00 และอยู่ในอันดับที่ 66 จากทั้งหมด 77 จังหวัด

**ข้อจำกัด:** ค่าเฉลี่ยดังกล่าวคำนวณจาก records และหมวดหมู่ข้อมูลในชุดข้อมูล ไม่ควรตีความว่าเป็นรายได้เฉลี่ยต่อครัวเรือนโดยตรง

### 2.3 การวิเคราะห์งบประมาณด้านภัยพิบัติ

**ตารางที่ใช้:** `disaster_budget`

วิเคราะห์ข้อมูลงบประมาณด้านภัยพิบัติในปี 2564 โดยเปรียบเทียบข้อมูลของแต่ละจังหวัด

**ข้อค้นพบ**
- จังหวัดนครศรีธรรมราชมีวงเงินอนุมัติสูงที่สุด จำนวน 148,773,631.24 บาท
- จังหวัดยโสธรมีวงเงิน 843,063 บาท และวงเงินอนุมัติ 843,063 บาท
- จังหวัดยโสธรมีค่าในช่องรวมทั้งสิ้น 4,083,729 บาท

**ข้อจำกัด:** ความหมายของคอลัมน์งบประมาณแต่ละประเภท เช่น `รวมทั้งสิ้น`, `วงเงิน` และ `วงเงินอนุมัติ` ยังต้องตรวจสอบเพิ่มเติม เนื่องจากค่าบางรายการไม่เท่ากัน และไม่ได้แทนค่า NULL ด้วยศูนย์

### 2.4 การวิเคราะห์จำนวนครัวเรือนที่ได้รับผลกระทบจากน้ำท่วม

**ตารางที่ใช้:** `flood_affected_households`

| ปี | จำนวนครัวเรือนรวมตามข้อมูล |
|---|---:|
| 2565 | 133 |
| 2566 | 173 |
| 2567 | 62 |

**ข้อค้นพบ**
- ปี 2566 มีจำนวนครัวเรือนที่ได้รับผลกระทบสูงที่สุด จำนวน 173 ครัวเรือน
- ปี 2567 จำนวนลดลงเหลือ 62 ครัวเรือน
- อำเภอตะกั่วป่ามีจำนวนครัวเรือนสูงที่สุดในปี 2565 และ 2566
- ในปี 2567 อำเภอท้ายเหมืองมีจำนวนครัวเรือนสูงที่สุด จำนวน 39 ครัวเรือน

**ข้อจำกัด:** จำนวนดังกล่าวเป็นผลรวมจาก records ในแต่ละปี ยังไม่สามารถยืนยันได้ว่าไม่มีการนับครัวเรือนซ้ำระหว่างรายการหรือพื้นที่

### 2.5 การวิเคราะห์ข้อมูลสรุปครัวเรือนที่ได้รับผลกระทบ

**ตารางที่ใช้:** `affected_households_summary`

ชุดข้อมูลนี้มีทั้งหมด 48 records ครอบคลุม 9 อำเภอในจังหวัดหนองคาย โดยมีข้อมูล 3 ประเภท ได้แก่ จำนวนครัวเรือนที่ได้รับผลกระทบ จำนวนตำบลที่เกิดภัย และจำนวนหมู่บ้านที่เกิดภัย

**ข้อค้นพบ**
- อำเภอเมืองหนองคายมีจำนวนครัวเรือนที่ได้รับผลกระทบสูงสุดที่รายงานไว้ 3,049 ครัวเรือน
- อำเภอโพนพิสัยมีจำนวนสูงสุด 1,044 ครัวเรือน
- อำเภอสระใครมีจำนวนสูงสุด 609 ครัวเรือน
- อำเภอเมืองหนองคายมีจำนวนตำบลที่เกิดภัยสูงสุด 11 ตำบล
- อำเภอเมืองหนองคายมีจำนวนหมู่บ้านที่เกิดภัยสูงสุด 60 หมู่บ้าน

**การตรวจสอบรอบรายงาน**

พบว่าข้อมูลของบางอำเภอมีหลายรอบรายงาน เช่น
- อำเภอท่าบ่อ มีข้อมูลครั้งที่ 3 และครั้งที่ 5
- อำเภอสระใคร มีข้อมูลครั้งที่ 1, 2 และ 5
- อำเภอโพนพิสัย มีข้อมูลครั้งที่ 3, 4 และ 7

จึงสามารถใช้คอลัมน์ `ครั้งที่` ในการแยกข้อมูลแต่ละรอบรายงานได้

**ข้อจำกัด:** ค่าที่นำเสนอเป็นค่าสูงสุดที่พบในแต่ละอำเภอ ไม่ใช่ยอดรวมสะสมของทุกรอบรายงาน และข้อมูลไม่มีวันที่รายงานที่ชัดเจน จึงไม่สามารถยืนยันแนวโน้มการฟื้นตัวจากจำนวนที่ลดลงได้

### 2.6 การวิเคราะห์ข้อมูลสถิติระดับหมู่บ้าน (Flood Village Statistics)

**ตารางที่ใช้:** `flood_village_stats`

ชุดข้อมูลนี้มีทั้งหมด 57,024 records ครอบคลุม 77 จังหวัด ใช้สำหรับวิเคราะห์ข้อมูลสถิติระดับหมู่บ้านและการรายงานข้อมูลในแต่ละปี

**ข้อค้นพบจากภาพรวม**
- ปี 2565 มี records ที่รายงานข้อมูลมากที่สุด จำนวน 36,354 records หรือ 63.75%
- ปี 2567 มี records ที่รายงานข้อมูลเพียง 207 records หรือ 0.36%
- จังหวัดนครราชสีมามีจำนวน records มากที่สุด 2,808 records
- จังหวัดยโสธรมี 883 records

**การวิเคราะห์ข้อมูลจังหวัดยโสธร**

เมื่อพิจารณาเฉพาะประเภทภัยอุทกภัย พบจำนวน records ที่มีข้อมูลในแต่ละปี ดังนี้

| ปี | จำนวน Records ที่มีข้อมูล |
|---|---:|
| 2562 | 861 |
| 2563 | 0 |
| 2564 | 181 |
| 2565 | 144 |
| 2566 | 436 |
| 2567 | 0 |

เมื่อตรวจสอบค่าตัวเลขในคอลัมน์รายปี พบว่า
- ปี 2562 และ 2565 มีค่าที่รายงานเป็น 1 ทั้งหมด
- ปี 2564 มี 28 records ที่มีค่าเท่ากับ 2
- ปี 2566 มี 2 records ที่มีค่าเท่ากับ 2
- เมื่อตรวจสอบ records ที่มีข้อมูลทั้งปี 2564 และ 2566 พบว่า 131 records มีค่าเปลี่ยนจาก 1 เป็น 1, 28 records เปลี่ยนจาก 2 เป็น 1 และ 2 records เปลี่ยนจาก 1 เป็น 2

**ข้อจำกัดและข้อสังเกต**
- จำนวน records ที่มีข้อมูลในแต่ละปีไม่ใช่จำนวนเหตุการณ์น้ำท่วมหรือจำนวนหมู่บ้านที่ได้รับผลกระทบโดยตรง
- ข้อมูลปี 2563 และ 2567 ของจังหวัดยโสธรไม่มีค่าที่รายงานในคอลัมน์รายปี
- ยังไม่สามารถระบุความหมายของค่าตัวเลข 1 และ 2 ได้อย่างชัดเจนจากข้อมูลที่มี จึงไม่ควรตีความว่าเป็นระดับความเสียหายหรือจำนวนเหตุการณ์โดยตรง
- การเปรียบเทียบระหว่างปีควรพิจารณาความครอบคลุมของข้อมูลและ records ที่มีข้อมูลทั้งสองปีร่วมด้วย

## 3. ข้อจำกัดของข้อมูลโดยรวม

จากการวิเคราะห์พบข้อจำกัดที่ควรพิจารณา ดังนี้

1. ข้อมูลแต่ละชุดครอบคลุมจังหวัดและปีที่แตกต่างกัน
2. ข้อมูลความเสี่ยงทางภูมิศาสตร์เป็นข้อมูลจังหวัดยโสธร ขณะที่ข้อมูลครัวเรือนที่ได้รับผลกระทบมาจากจังหวัดหนองคายและพังงา จึงไม่สามารถนำมา JOIN เพื่อวิเคราะห์ความสัมพันธ์โดยตรงได้
3. บางตารางไม่มีวันที่หรือช่วงเวลาที่แน่นอนในการรายงาน
4. ข้อมูลจากหลายรอบรายงานไม่ควรนำมาบวกกันโดยไม่มีหลักฐานว่าเป็นข้อมูลคนละกลุ่ม
5. ค่า NULL หมายถึงไม่มีข้อมูล ไม่ควรตีความว่าเป็นศูนย์
6. ค่าเฉลี่ยรายได้เป็นค่าเฉลี่ยจาก records ในชุดข้อมูล ไม่ใช่ค่าเฉลี่ยรายได้ระดับครัวเรือนโดยตรง

## 4. สรุปสถานะการดำเนินงาน

จากการดำเนินงานที่ผ่านมา ได้ดำเนินการวิเคราะห์และจัดทำเอกสารประกอบโครงการแล้ว ดังนี้

### 4.1 งานที่ดำเนินการแล้ว
1. วิเคราะห์การกระจายระดับความเสี่ยงทางภูมิศาสตร์จากตาราง `geographic`
2. วิเคราะห์ข้อมูลรายได้และกลุ่มเศรษฐกิจจากตาราง `nso_income`
3. วิเคราะห์ข้อมูลงบประมาณด้านภัยพิบัติจากตาราง `disaster_budget`
4. วิเคราะห์จำนวนครัวเรือนที่ได้รับผลกระทบจากตาราง `flood_affected_households`
5. วิเคราะห์ข้อมูลสรุปครัวเรือน ตำบล และหมู่บ้านจากตาราง `affected_households_summary`
6. วิเคราะห์ข้อมูลสถิติระดับหมู่บ้านจากตาราง `flood_village_stats`
7. ตรวจสอบคุณภาพข้อมูลทั้ง 7 ตาราง และจัดทำเอกสาร `data-quality-summary.md`
8. จัดทำเอกสารโครงสร้างและความสัมพันธ์ของข้อมูล `data-model.md`

### 4.2 งานที่ต้องดำเนินการต่อ
1. ตรวจสอบและรวบรวม SQL Query ที่ใช้ในการวิเคราะห์ให้ครบถ้วน
2. ตรวจสอบความถูกต้องและความสอดคล้องระหว่างผลลัพธ์จาก Athena กับเอกสารสรุป
3. สรุปข้อค้นพบ ข้อจำกัด และข้อเสนอแนะให้เชื่อมโยงกับคำถามหลักของโครงการ
4. เตรียมหลักฐานการทำงานและผลลัพธ์สำหรับนำเสนอใน Term Project
