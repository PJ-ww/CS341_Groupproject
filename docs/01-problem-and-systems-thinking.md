# 1. Problem & Systems Thinking

## 1.1 ที่มาและปัญหาของโครงการ

จังหวัดเชียงใหม่เกิดอุทกภัยเกือบทุกปี ทั้งน้ำป่าไหลหลากในพื้นที่ภูเขา และน้ำล้นตลิ่งในพื้นที่ราบริมแม่น้ำ แต่ละหมู่บ้านได้รับผลกระทบไม่เท่ากัน บางหมู่บ้านถูกรายงานซ้ำทุกปี บางหมู่บ้านไม่เคยถูกรายงาน และหมู่บ้านแต่ละแห่งมีลักษณะพื้นที่ จำนวนประชากร และรายได้ครัวเรือนต่างกัน

หน่วยงานที่ต้องจัดสรรความช่วยเหลือซึ่งมีจำกัดจึงต้องรู้ว่าพื้นที่ใดได้รับผลกระทบมากหรือซ้ำ และพื้นที่ใดเปราะบาง แต่ข้อมูลที่ใช้ตอบเรื่องนี้กระจายอยู่หลายไฟล์ คนละรูปแบบ (CSV, XLSX, JSON) คนละระดับพื้นที่ (หมู่บ้าน, อำเภอ) และมีค่าว่างมาก

โครงการนี้จึงสร้าง data pipeline ที่รวบรวม ตรวจสอบ และเชื่อมข้อมูลเหล่านี้ในระดับหมู่บ้านอย่างตรวจสอบย้อนกลับได้ เพื่อตอบคำถามวิจัย และระบุให้ชัดว่าข้อมูลตอบอะไรได้และไม่ได้

## 1.2 คำถามวิจัย

1. **Q1:** พื้นที่ใดในจังหวัดเชียงใหม่ได้รับผลกระทบจากอุทกภัยมากที่สุด และรูปแบบผลกระทบเปลี่ยนแปลงอย่างไรในแต่ละปี?
2. **Q2:** ลักษณะทางภูมิศาสตร์และประชากรของหมู่บ้าน (ติดแม่น้ำ ติดภูเขา ประชากร รายได้ครัวเรือน) มีความสัมพันธ์กับผลกระทบจากอุทกภัยหรือไม่?
3. **Q3:** หากทรัพยากรช่วยเหลือมีจำกัด ควรจัดลำดับความสำคัญของหมู่บ้านและอำเภอที่ควรได้รับความช่วยเหลืออย่างไร?

คำถามชุดนี้ใช้ตรงกันทุกที่: [`README.md`](../README.md), [`transformation/README.md`](../transformation/README.md), [`docs/06-storage-data-model-query.md`](06-storage-data-model-query.md) และ SQL ใน `sql/curated/queries/` (`q1_*`, `q2_*`, `q3_*`)

## 1.3 การเปลี่ยนคำถามวิจัยจาก proposal

คำถามชุดแรกใน proposal (Checkpoint 1) คือ

1. เมื่อระดับน้ำท่วมใกล้เคียงกัน ปัจจัยอะไรบ้างที่อาจทำให้แต่ละพื้นที่ได้รับความเสียหายไม่เท่ากัน?
2. ปัจจัยอะไรบ้างที่เกี่ยวข้องกับการฟื้นตัวจากน้ำท่วม และการได้รับความช่วยเหลือมีความสัมพันธ์กับการฟื้นตัวเร็วขึ้นหรือไม่?
3. หากมีทรัพยากรช่วยเหลือจำกัด ควรให้ความสำคัญกับพื้นที่หรือครัวเรือนกลุ่มใดก่อน?

**เหตุผลที่เปลี่ยน** (proposal ระบุไว้แล้วว่าจะตรวจข้อมูลจริงก่อน และปรับระดับการวิเคราะห์ตามข้อมูล)

| ปัญหาที่พบเมื่อตรวจไฟล์จริง | ผลต่อคำถาม |
|---|---|
| ไม่มีข้อมูลระยะเวลาฟื้นตัวในทุกแหล่ง และข้อมูลความช่วยเหลือที่หาได้ (วงเงินปี 2564 รายจังหวัด) เชื่อมกับพื้นที่ที่ได้รับผลกระทบไม่ได้ | ตัดคำถามข้อ 2 เดิม (การฟื้นตัว) ออก เพราะตอบด้วยข้อมูลไม่ได้ |
| ไม่มีข้อมูลระดับน้ำ/ความลึกน้ำ | ข้อ 1 เดิมตั้งเงื่อนไข "ระดับน้ำใกล้เคียงกัน" ไม่ได้ จึงปรับเป็น Q2 ที่ดูความสัมพันธ์ระหว่างลักษณะพื้นที่กับการถูกรายงาน (เชิงพรรณนา) |
| ข้อมูลชุดเดิมอยู่คนละจังหวัด (หนองคาย พังงา ยโสธร) คนละระดับพื้นที่ และปีแทบไม่ซ้อนกัน เชื่อมกันได้จริงเพียง 10 แถว | จำกัดขอบเขตเป็นจังหวัดเชียงใหม่ ซึ่งมีข้อมูลรายงานอุทกภัย ข้อมูลหมู่บ้าน และรายได้ที่ใช้รหัส/ชื่อหมู่บ้านร่วมกัน |
| ข้อมูลระดับครัวเรือนรายตัวไม่มี | ข้อ 3 เดิมปรับเป็น Q3 ระดับหมู่บ้านและอำเภอ ไม่ใช่รายครัวเรือน |
| ต้องรู้ก่อนว่าพื้นที่ใดได้รับผลกระทบและเปลี่ยนอย่างไร จึงจะเทียบปัจจัยหรือจัดลำดับได้ | เพิ่ม Q1 เป็นฐานของการวิเคราะห์ |

รายละเอียดข้อมูลชุดเดิมและชุดใหม่อยู่ใน [`data_catalog/sources.md`](../data_catalog/sources.md) หัวข้อ 6

## 1.4 การมองปัญหาอย่างเป็นระบบ

ปัจจัยที่พิจารณาและข้อมูลที่ใช้แทน

| ปัจจัย | ข้อมูลที่ใช้ | ตัวชี้วัด |
|---|---|---|
| การเกิดอุทกภัย | รายงานเหตุการณ์อุทกภัยรายหมู่บ้าน ปภ. 2566–2567 | จำนวนครั้ง/ปีที่หมู่บ้านถูกรายงาน, หมู่บ้านที่ถูกรายงานซ้ำทั้งสองปี |
| ความเสียหาย | ข้อมูลความเสียหายเชียงใหม่ 2563–2567 | ผู้ได้รับผลกระทบ ครัวเรือน บ้านเสียหาย รายอำเภอ |
| ลักษณะพื้นที่ | ข้อมูลพื้นฐานรายหมู่บ้าน | ติดแม่น้ำ ติดภูเขา พิกัด |
| ประชากร | ข้อมูลพื้นฐานรายหมู่บ้าน | ประชากร จำนวนครัวเรือน |
| ทรัพยากรของครัวเรือน | รายได้ครัวเรือนเฉลี่ยรายหมู่บ้าน | รายได้ (บาท/ปี), quartile รายได้ |
| ความต้องการความช่วยเหลือ | รวมจากด้านบน | คะแนนจัดลำดับ Q3 (ความถี่ 0.5 / ครัวเรือน 0.3 / รายได้ต่ำ 0.2) |

ปัจจัยเหล่านี้อาจเกี่ยวข้องกัน เช่น หมู่บ้านริมแม่น้ำอาจถูกรายงานบ่อยกว่า และหมู่บ้านที่มีรายได้ต่ำอาจรับมือได้น้อยกว่า แต่ความสัมพันธ์เหล่านี้เป็นสิ่งที่ต้องตรวจจากข้อมูล ไม่ใช่ข้อสรุปที่ยืนยันแล้ว และผลที่ได้เป็นความสัมพันธ์เชิงพรรณนา ไม่ใช่เหตุและผล

## 1.5 ขอบเขตของโครงการ

- **พื้นที่:** จังหวัดเชียงใหม่ 25 อำเภอ ระดับหมู่บ้าน (2,184 หมู่บ้านหลัง validation)
- **ช่วงเวลา:** รายงานอุทกภัย 2566–2567, ความเสียหาย 2563–2567, ข้อมูลหมู่บ้านและรายได้ไม่มีปี (ใช้เป็นคุณลักษณะคงที่)
- **ระดับการสรุป:** หมู่บ้านและอำเภอ ไม่สรุปรายครัวเรือน
- **ไม่อยู่ในขอบเขต:** การฟื้นตัว ผลของความช่วยเหลือ และการเปรียบเทียบกับจังหวัดอื่น

## 1.6 ผลลัพธ์ที่คาดหวัง

- รายชื่อหมู่บ้าน/อำเภอที่ได้รับผลกระทบมากและเปลี่ยนแปลงระหว่างปี (Q1)
- ตารางเปรียบเทียบสัดส่วนการถูกรายงานตามลักษณะพื้นที่ ประชากร และรายได้ (Q2)
- รายการจัดลำดับหมู่บ้านและอำเภอที่ตรวจสอบย้อนกลับได้ พร้อมน้ำหนักที่ระบุชัด (Q3)
- คำอธิบายข้อจำกัดของข้อมูลและผลต่อการตีความ
