# 2. Initial Data Architecture & Decisions

## 2.1 แนวทางการจัดการข้อมูลเบื้องต้น

ทีมวางแผนจัดการข้อมูลตามลำดับดังนี้

1. รวบรวมข้อมูลจากแหล่งข้อมูลที่เลือก
2. เก็บข้อมูลต้นฉบับไว้โดยไม่แก้ไข
3. ตรวจสอบความถูกต้องและความครบถ้วนของข้อมูล
4. ทำความสะอาดและปรับรูปแบบข้อมูล
5. เชื่อมข้อมูลจากหลายแหล่ง หากพื้นที่และช่วงเวลาสอดคล้องกัน
6. นำข้อมูลที่เตรียมแล้วไปวิเคราะห์
7. สรุปผลเป็นตาราง กราฟ และข้อค้นพบ

## 2.2 แหล่งข้อมูลที่วางแผนจะใช้

- สถิติอุทกภัยรายหมู่บ้านจาก ปภ.
- ข้อมูลรายได้จาก NSO
- ข้อมูลการให้ความช่วยเหลือผู้ประสบอุทกภัยในช่วงฤดูฝน
- ข้อมูลจำนวนครัวเรือนที่ได้รับเงินเยียวยา

ทีมจะตรวจสอบรายละเอียดของไฟล์จริงก่อนตัดสินใจเลือกข้อมูลสำหรับการวิเคราะห์ขั้นสุดท้าย

## 2.3 ขั้นตอนการจัดการข้อมูล

### ขั้นที่ 1: รวบรวมข้อมูล

ดาวน์โหลดข้อมูลจากแหล่งที่เลือก และบันทึกลิงก์ที่มา รูปแบบไฟล์ ช่วงปี และพื้นที่ที่ครอบคลุม

### ขั้นที่ 2: ตรวจสอบข้อมูล

ตรวจสอบชื่อคอลัมน์ ชนิดข้อมูล ค่าที่หายไป ข้อมูลซ้ำ และค่าที่ไม่ถูกต้อง

### ขั้นที่ 3: ทำความสะอาดข้อมูล

ปรับชื่อคอลัมน์และรูปแบบข้อมูลให้สอดคล้องกัน เช่น รูปแบบปีและชื่อพื้นที่ พร้อมบันทึกปัญหาที่พบ

### ขั้นที่ 4: เชื่อมข้อมูล

ตรวจสอบว่าข้อมูลแต่ละชุดสามารถเชื่อมกันได้ตามพื้นที่และปีหรือไม่ หากระดับข้อมูลต่างกัน ต้องระบุข้อจำกัดก่อนนำมาวิเคราะห์ร่วมกัน

### ขั้นที่ 5: วิเคราะห์ข้อมูล

ใช้ SQL หรือ Python เพื่อสรุปข้อมูลผลกระทบจากน้ำท่วมและการช่วยเหลือ พร้อมจัดทำตารางหรือกราฟเพื่อแสดงผล

## 2.4 การตัดสินใจเบื้องต้น

- เก็บข้อมูลต้นฉบับไว้เพื่อใช้ตรวจสอบย้อนหลัง
- บันทึกแหล่งที่มาของข้อมูลและขั้นตอนการจัดการข้อมูล
- แยกข้อมูลที่ผ่านการทำความสะอาดออกจากข้อมูลต้นฉบับ
- ตรวจสอบพื้นที่และช่วงปีก่อนเชื่อมข้อมูล
- ไม่สรุปผลในระดับครัวเรือน หากข้อมูลรองรับเพียงระดับพื้นที่
- เลือกเครื่องมือที่จะใช้จริงหลังตรวจสอบรูปแบบและขนาดข้อมูล รวมถึงข้อกำหนดของรายวิชา

## 2.5 ปัญหาที่อาจพบ

- ข้อมูลมีระดับพื้นที่แตกต่างกัน
- ข้อมูลครอบคลุมช่วงปีไม่ตรงกัน
- ข้อมูลรายได้อาจไม่มีรายละเอียดระดับครัวเรือน
- อาจไม่มีข้อมูลระยะเวลาฟื้นตัวโดยตรง
- ข้อมูลอาจมีค่าว่างหรือรูปแบบไม่สอดคล้องกัน

## 2.6 ผลลัพธ์ที่ต้องการ

- รายการแหล่งข้อมูลที่ใช้
- สรุปผลการตรวจสอบคุณภาพข้อมูล
- ชุดข้อมูลที่ผ่านการทำความสะอาด
- ชุดข้อมูลที่เชื่อมกันได้ หากมีความเป็นไปได้
- คำสั่ง SQL หรือ Notebook สำหรับวิเคราะห์
- ตาราง กราฟ และสรุปผลการวิเคราะห์
