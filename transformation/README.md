# การแปลงและประมวลผลข้อมูล (Data Transformation & Processing)

## ภาพรวม (Overview)

โมดูลนี้มีหน้าที่แปลงชุดข้อมูลที่ผ่านการตรวจสอบความถูกต้องแล้ว ซึ่งเกี่ยวข้องกับสถานการณ์น้ำท่วม ให้อยู่ในรูปแบบที่เป็นมาตรฐานและเหมาะสมสำหรับการนำไปวิเคราะห์ต่อไป

## หน้าที่รับผิดชอบ (Responsibilities)

- ทำความสะอาดชุดข้อมูลที่ผ่านการตรวจสอบแล้ว
- ปรับมาตรฐานชื่อคอลัมน์ ชนิดข้อมูล วันที่ และข้อมูลทางภูมิศาสตร์ให้เป็นรูปแบบเดียวกัน
- สร้างฟิลด์หรือคอลัมน์ใหม่จากข้อมูลเดิมเมื่อมีความจำเป็น
- รวมชุดข้อมูลเข้าด้วยกันเมื่อมีคีย์สำหรับเชื่อมโยงข้อมูลที่สามารถใช้ร่วมกันได้
- ส่งออกชุดข้อมูลที่ผ่านการแปลงแล้ว เพื่อนำไปใช้ในขั้นตอนการประมวลผลและการวิเคราะห์ต่อไป

## ข้อมูลนำเข้า (Input)

ชุดข้อมูลที่ผ่านขั้นตอนการตรวจสอบความถูกต้องจากโมดูล Data Validation

## ผลลัพธ์ (Output)

ชุดข้อมูลที่ผ่านการแปลงและประมวลผลแล้ว โดยส่งออกในรูปแบบ CSV และ/หรือ Parquet

## เครื่องมือที่ใช้ (Tools)

- Python
- Pandas
- PyArrow
- Boto3 (สำหรับเชื่อมต่อและจัดการข้อมูลบน AWS S3)

## หมายเหตุ (Notes)

รายละเอียดของขั้นตอนการแปลงข้อมูลและโครงสร้างของข้อมูลผลลัพธ์ จะกำหนดให้ชัดเจนหลังจากได้รับและตรวจสอบชุดข้อมูลจริงที่ผ่านการตรวจสอบความถูกต้องแล้ว
